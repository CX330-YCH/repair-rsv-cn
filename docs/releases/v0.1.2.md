# v0.1.2 — 修复 RSV 音视频边界，新增文件信息与中文界面

这是本改进版的首次公开发布，汇总了恢复引擎修复和桌面 App 改进。基于 [macmixing/repair-rsv](https://github.com/macmixing/repair-rsv)，保留原项目版权声明和许可证。

## 修复的问题

- 修复部分 Sony RSV 恢复后音频被错误并入视频样本的问题，消除由此引起的周期性解码失败、画面卡顿、声音断续及音轨缩短。
- 不再仅凭第一组数据的 NAL 长度确定全片音频块大小；新增 NAL 头、类型、边界、PCM 采样对齐及多个完整分组的交叉校验。
- 修复尾部截断处理，保留已确认完整的视频帧，排除截断样本，避免将尾部视频残片作为 PCM 音频读取。
- 根据实际 NAL 类型识别关键帧，修正显示时间表超出实际样本数的问题。
- 修复 App 输出路径与恢复引擎实际路径可能不一致的问题，并在报告成功前确认输出文件存在且非空。
- 改进任务状态锁定及日志收尾，避免重复启动和迟到日志覆盖完成状态；极短或空输入按失败处理。

## 新增与改进

- 在两个输入文件选择区域下方显示可读取的分辨率、帧率、时长、大小、视频编码、位深和音频参数。
- 在进度条下方显示修复结果的媒体参数、视频帧数和音频时长。
- 新增简体中文 / English 切换、系统语言识别与语言偏好保存，并适配中文菜单及原生文件选择器。
- 去掉无结果时的占位说明，只显示实际参数、进度、结果和必要的错误信息，运行日志可折叠查看。
- 新增随包引擎 `--probe` JSON 媒体信息接口，App 不需要用户额外安装 FFprobe。
- 支持默认本地签名打包，新增解析器、恢复流程及媒体信息回归测试。

## 实测结果

在一份 1080p / 50 fps / H.264 High 4:2:2 10 bit、48 kHz / 16 bit 双声道 PCM 的真实 RSV 样本上：

- 实际可解码画面由 2,980 帧恢复为 **3,108 帧**，相邻显示时间全部为 **20 ms**。
- 音频轨由约 18.02 秒恢复为 **61.92 秒**，完整视频轨为 **62.16 秒**。
- 全片严格音视频解码、时间戳、回归测试及人工声音与口型回放检查通过。
- App 输出与独立索引校正验证文件逐字节一致。

该结果来自具体样本，不保证适用于所有损坏文件。缺失的尾部数据不会补造；HEVC 的当前验证以解析器合成数据为主。测试媒体不会公开上传。
